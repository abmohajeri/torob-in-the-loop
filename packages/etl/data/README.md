# packages/etl/data: curated reference data

These hand-curated JSON files are read by the ETL. The ETL normalizes every key and value with `normalizeForSearch` from `@titl/shared`, so the files hold raw Persian/English text. Each file is regenerated by a script under `packages/etl/scripts/curation/`. Edit the script's source tables, not the JSON, and then rerun the script. Every generator accepts `--dry`.

Source dataset (read-only): `../../../../dataset/{shops,products,offers}.csv` (Torob hackathon dataset).

## taxonomy.json
- **Shape:** `{ version, groups: { <leaf category exactly as in products.csv>: <groupId> }, aliases: { <leaf>: [alias…] } }`
- **Coverage:** all 3,428 leaf categories in products.csv are mapped once each, to the 20 group ids in `CATEGORY_GROUPS` (`packages/shared/src/constants.ts`). Only 5 categories (7 products) are in `other`: gift cards, «پی ست» (1 ambiguous title), real estate, a redacted title, e-cigarette accessories. These have no honest group.
- **Method:** `taxonomy-rules.ts` holds explicit overrides plus ordered keyword rules. Ambiguous categories were reviewed manually against sample product titles. `check-taxonomy-cooccurrence.ts` flags any leaf whose shops mostly sell another group's categories.
- **Aliases:** 692 categories carry 2,739 aliases. These cover the top ~400 categories by product count plus categories that shoppers name colloquially. They are hand-written in `category-aliases.ts` and include colloquial terms, misspellings and English terms. `audit-aliases.ts` lists aliases that span several categories or groups, for drift review.
- **Regenerate:** `npx tsx packages/etl/scripts/curation/build-taxonomy.ts`

## synonyms.json
- **Shape:** `{ <term>: [<expansion>…] }`. The file has 1,400 keys and 3,503 expansions.
- **Source:** about 430 hand-written synonym groups in `build-synonyms.py`. The script expands each group symmetrically, so every member becomes a key. This is why the key count is above 600.
- **Content:** colloquial and formal pairs (کتونی/کتانی, گوشی/موبایل), half-space, space and joined spelling variants, English and Persian product terms (airpods, powerbank) and units (گیگ/گیگابایت/gb, اینچ/inch).
- **Precision:** expansions are deliberately narrow. Hypernyms that would bring in unrelated results are excluded; for example, «کفش» does not expand to «کتانی».
- **Regenerate:** `python3 -I packages/etl/scripts/curation/build-synonyms.py`

## brands.json
- **Shape:** `{ version, brands: [{ name, en|null, aliases[] }] }`. The file has 1,386 brands.
- **Coverage:** includes every dataset `brand_name` with 3 or more products (1,369; the literal string `null` is excluded). It also includes major brands that appear in titles without a `brand_name`, such as Nike, Vans, Converse and Anker. These were checked with title LIKE queries.
- **English names:** taken from `brand-manual.ts`, from Latin spec values («برند», «شرکت سازنده») that sound like the Persian name, or from Latin words that recur in that brand's titles. If none of these sources gives a confident answer, `en` is left as `null`; 733 brands have no English name. Unknown stays unknown.
- **Alias policy:** aliases are conservative. No alias is a common Persian word. Sub-lines map only to their true parent, for example Redmi/POCO to Xiaomi and Galaxy to Samsung.
- **Regenerate:** `npx tsx packages/etl/scripts/curation/build-brands.ts`

## places.json
- **Shape:** `{ version, places: [{ id, name, kind: landmark|area, lat, lng, subtitle, weight }] }`. There are 103 places: 57 landmarks and 46 areas.
- **Coordinate sources (approximate, target within ~300 m):**
  1. OSM metro station coordinates (`osm/metro.json`) for squares and places named after a station.
  2. The mean lat/lon of dataset shops whose address mentions the place, used for passages and shopping streets. Examples: پاساژ علاءالدین (171 shops), چارسو (171), لاله‌زار (about 1.5k).
  3. Hand placement from local knowledge for malls with no shops in the dataset, such as Iran Mall, Palladium and Tirajeh, and for broad neighbourhoods. Area entries are rough neighbourhood centres.
- **Validation:** the script checks for unique ids, the Tehran bounding box, valid kind values and weights in (0, 1]. It also prints each place's distance to the nearest metro station as a sanity check.
- **Caveat:** treat all coordinates as **approximate**. They are suitable for "near me" ranking, not for navigation. A weight of 1.0 marks the most popular picks.
- **Regenerate:** `python3 -I packages/etl/scripts/curation/build-places.py`
